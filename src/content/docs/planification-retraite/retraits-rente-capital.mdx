À la retraite, la question change : il ne s'agit plus seulement d'accumuler, mais d'utiliser le patrimoine sans l'épuiser trop vite et sans prendre un risque excessif.

<CardGrid>
	<Card title="Capital" icon="stack">
		Une somme disponible, utilisable en une ou plusieurs fois.
	</Card>
	<Card title="Rente" icon="repeat">
		Un revenu régulier, souvent associé à une protection contre le risque de longévité.
	</Card>
	<Card title="Retraits programmés" icon="clock">
		Des ventes ou retraits réguliers selon une règle définie à l'avance.
	</Card>
</CardGrid>

## Les risques de décumulation

| Risque | Description | Piste de gestion |
| :-- | :-- | :-- |
| Longévité | Vivre plus longtemps que prévu | Rente, marge de sécurité |
| Séquence de rendements | Mauvaises années au début des retraits | Réserve liquide, allocation prudente |
| Inflation | Perte de pouvoir d'achat | Actifs réels, révision des retraits |
| Fiscalité | Imposition différente selon l'enveloppe | Planifier les sources de retrait |

<Aside type="caution" title="Fiscalité">
	Les règles de sortie changent selon l'enveloppe, le type de versement et la date de retrait. Vérifiez les règles applicables avant de publier un exemple chiffré.
</Aside>

## Exemple de plan de page

1. Définir le besoin annuel.
2. Identifier les enveloppes mobilisables.
3. Classer les retraits par fiscalité et liquidité.
4. Prévoir une réserve pour les années défavorables.
5. Réviser le plan chaque année.
