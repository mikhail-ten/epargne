Le plan d'épargne en actions, ou PEA, est une enveloppe destinée à investir en actions européennes directement ou via certains fonds éligibles. Il est souvent utilisé pour l'investissement long terme.

## Pourquoi l'étudier ?

| Atout | Contrepartie |
| :-- | :-- |
| Cadre fiscal spécifique | Contraintes sur les titres éligibles |
| Orientation long terme | Retraits à analyser selon l'ancienneté |
| Accès à des fonds et ETF éligibles | Plafond de versement |

<Aside type="caution" title="Éligibilité">
	Un produit “actions” n'est pas automatiquement éligible au PEA. Vérifiez toujours l'éligibilité auprès de l'intermédiaire ou de la documentation du fonds.
</Aside>

## Bon usage éditorial

Pour rédiger une page PEA complète, séparez clairement :

- ce que l'enveloppe permet de détenir ;
- les règles de versement ;
- les règles de retrait ;
- la fiscalité ;
- les frais de l'intermédiaire ;
- les limites par rapport au compte-titres ordinaire.

## Exemple de bloc à compléter

```md
PEA choisi : ...
Frais de courtage : ...
Frais de tenue de compte : ...
Supports principaux : ...
Objectif : ...
Horizon : ...
```
